# Dashboard

The dashboard shows a simple overview of the active vehicle.

Inspired by Apple Health:

- minimal
- clear
- insight focused

---

## Metrics

The dashboard will display:

Total fuel or energy spent

Total maintenance cost

Tracked distance

Ownership distance

Cost per km

Active vehicle
