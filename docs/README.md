# DriveCost Documentation

Use this directory by responsibility rather than by historical document name.

| Document | Authority |
| --- | --- |
| [Product overview](product-overview.md) | High-level orientation only. |
| [Product principles](product-principles.md) | Product philosophy, user value, and experience standards. |
| [Cost semantics](cost-semantics.md) | Definitions and limits of cost calculations. |
| [Product roadmap](product-roadmap.md) | Product sequencing and intended user outcomes. |
| [Development roadmap](development-roadmap.md) | Engineering progress and operational readiness. |
| [App architecture](app-architecture.md) | Current system structure and technical boundaries. |
| [Architecture decisions](architecture-decisions.md) | Recorded architectural decisions and their rationale. |
| [Definition of Done](definition-of-done.md) | Delivery and quality gates for implementation work. |

When documents appear to conflict, resolve the question using the authority in
this table. Escalate a genuine conflict between a product principle, cost
semantic, and architectural decision instead of silently changing behaviour.
