# DriveCost MVP Scope

The first version focuses on validating the concept.

## Required features

Garage

- add vehicle
- list vehicles
- edit vehicle
- store richer vehicle metadata locally
- store locally

Dashboard

- cost summary cards
- recent event timeline
- tracked distance and ownership distance visibility

Tracking

- fuel entries
- EV charging entries using the same local flow
- maintenance entries

Sync

- local outbox with optional authenticated backup and two-device sync
- clear local-only, waiting, syncing, synced, and recoverable-error states

## Not included yet

- analytics
- charts
- subscriptions
- cross-device accounts
- external vehicle data integrations

Those will be implemented later.
